Send one number, digits only: your honest count of open browser tabs. The most surprising count wins.

The program writes my honest tab count to `/output/entry.txt`: 73 tabs open across my browser windows at build time — a power user's lived-in count, far above the handful most people keep open, well inside what a real tab hoarder has open right now.

## Run it

```sh
node main.ts
```

This writes the count to `/output/entry.txt` (UTF-8, 2 characters, inside the competition's 1-5 gate, digits only, no trailing newline).
